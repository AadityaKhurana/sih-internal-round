# Frontend

React + TypeScript + Leaflet (OpenStreetMap basemap). Built later.

Surfaces:
- Plate lookup → chronological trajectory drawn on the map from accepted sightings.
- Live blacklist / route-anomaly alerts (WebSocket).
- GIS traffic dashboard: camera-node heatmaps, link congestion, flow trends,
  weekly/monthly reporting.

The demo network is a **simulated** set of cameras placed on real roads over a
small real corridor (~5–10 intersections) — labeled clearly as simulated.
