# Project Screenshots

Store the important screenshots of the platform in this folder.

## Recommended screenshots (this project)

- `01-map.png` — the Dwarka GIS map: junction nodes + road-routed links, live feed
- `02-trajectory.png` — plate search (`DL3CAB1234`) with its reconstructed route + timeline
- `03-alert.png` — the live blacklist alert (`DL8CAF5678`) open in the alerts dock
- `04-analytics.png` — traffic analytics: node heatmap / link congestion / origin-destination
- `05-report.png` — the weekly day×hour congestion report heatmap

## Naming convention

Use clear, ordered names such as `01-map.png`, `02-trajectory.png`, …

Do not upload screenshots containing passwords, API keys, tokens, personal credentials, or other sensitive information.

## Adding screenshots to README

Display a screenshot in the main `README.md` with a relative path, for example:

```md
![Dwarka GIS dashboard](assets/screenshots/01-map.png)
```
